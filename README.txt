My Journal: private habit, mood and thoughts app. Works offline.

Free hosting on GitHub Pages (note: the repo must be public on the free plan; your entries stay on your own device):
1. Create a GitHub account and a new repository.
2. Upload all files from this folder (index.html, sw.js, manifest.webmanifest, icons).
3. Repo Settings > Pages > deploy from the main branch.
4. Open the link on your phone, then Add to Home Screen. It works offline after the first load.

Alternative: drag this folder onto netlify.com/drop.

Your data is stored only in your browser on that device.
